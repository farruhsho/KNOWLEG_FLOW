> production. Пункты помечены: **[код]** — сделано или делается в

## 2. Идентификатор приложения

Сейчас `applicationId` и `namespace` — шаблонные `com.example.knowledge_flow`,
iOS bundle id — `com.example.knowledgeFlow`. **После первой загрузки в Play
идентификатор изменить нельзя.**

Рекомендация: **`kg.ortmaster.app`** (обратная запись домена; желательно
владеть доменом `ortmaster.kg` или выбрать id по реальному домену).

Шаги:

       `applicationId` = `kg.ortmaster.app`.

       `android/app/src/main/kotlin/kg/ortmaster/app/` и поменять строку
       `package`.
3. [ ] **[код]** iOS: bundle id в Xcode (`Runner` → Signing) — тот же
       `kg.ortmaster.app`, если нужен iOS.
4. [ ] **[владелец]** Firebase Console → проект **`knowleg-33f36`** (тот же
       проект — иначе потеряются все UID и данные) → «Добавить приложение
       Android» с новым id.
5. [ ] **[владелец]** Скачать новый `android/app/google-services.json` (файл
       в `.gitignore`, в git не коммитить; в CI — из секрета).
6. [ ] **[код]** `flutterfire configure --project=knowleg-33f36` —
       перегенерировать `lib/firebase_options.dart` с новыми app id.
7. [ ] **[владелец]** Добавить отпечатки **SHA-1 и SHA-256** в настройки

       приложения» → «Подпись приложения»). Без этого вход через Google в
       release-сборке не работает (REL-03). Затем заново скачать

8. [ ] **[владелец]** App Check: Firebase Console → App Check → приложение

       права Owner). Включать принудительную проверку для Firestore/Functions

       проходит.
9. [ ] **[владелец]** Старое Android-приложение `com.example.knowledge_flow` в

## 3. Подпись: upload-ключ и Play App Signing

- [ ] **[владелец]** Создать upload-ключ (пример):
      `keytool -genkeypair -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload`
- [ ] **[владелец]** Создать `android/key.properties` (в `.gitignore`) в формате,
      который читает `android/app/build.gradle.kts`:

      ```properties
      storeFile=<абсолютный или относительный путь к upload-keystore.jks>
      storePassword=<пароль хранилища>
      keyAlias=upload
      keyPassword=<пароль ключа>
      ```

- [ ] **[владелец]** Сделать две резервные копии `.jks` и паролей в разных
      защищённых местах. Потеря upload-ключа решается через сброс в Play
      Console, но это время.
- [ ] **[владелец]** Play App Signing включён по умолчанию для новых
      приложений — принять. Ключ подписи приложения хранит Google.
- [ ] **[тест]** ⚠️ Если `key.properties` нет, `build.gradle.kts` подписывает
      release **debug-ключом**. Такой AAB загружать нельзя. Перед загрузкой:
      `keytool -printcert -jarfile build/app/outputs/bundle/release/app-release.aab`
      — владелец сертификата должен быть upload-ключом, а не
      `CN=Android Debug`.
- [ ] **[код, рекомендация]** Сделать отсутствие `key.properties` ошибкой
      сборки для release (REL-01), а для локального запуска использовать
      `flutter run --profile`.

## 5. Версии и сборка

- Версия задаётся в `pubspec.yaml` (`version: 1.0.0+1` → `versionName` 1.0.0,
  `versionCode` 1). Каждая загрузка в Play требует **нового versionCode**.
- Сборка AAB (APK для Play не используется):

  ```bash
  flutter pub get
  flutter build appbundle --release \
    --build-name=1.0.0 --build-number=<N> \
    --dart-define=BILLING_MODE=external \
    --obfuscate --split-debug-info=build/symbols
  ```

  `BILLING_MODE=play` — только если владелец выбрал продажи через Google Play
  (см. [`BUSINESS_MODEL.md`](BUSINESS_MODEL.md)). Результат:
  `build/app/outputs/bundle/release/app-release.aab`.
- [ ] **[владелец/CI]** Загрузить символы Dart для Crashlytics
      (`firebase crashlytics:symbols:upload --app=<ANDROID_APP_ID> build/symbols`);
      файл маппинга R8 загружает Gradle-плагин Crashlytics.
- [ ] **[код]** Версия в `app_constants.dart` дублирует `pubspec.yaml` (VER-01) —
      читать из `package_info_plus` или удалить дубль.
- [ ] **[CI]** Номер сборки из `github.run_number`, `google-services.json` и
      `key.properties` — из секретов (CI-02).

## 6. Разрешения

Основной манифест объявляет только `INTERNET`. Остальное приходит из плагинов
при слиянии манифестов. Проверить итоговый манифест (Android Studio → Merged
Manifest или `build/app/intermediates/merged_manifests/release/`).

| Разрешение | Откуда | Нужно? | Действие |
|---|---|---|---|
| `INTERNET` | основной манифест | да | — |
| `ACCESS_NETWORK_STATE` | `connectivity_plus`, Firebase | да (офлайн-индикатор) | — |
| `POST_NOTIFICATIONS` | `firebase_messaging` | да, если включены напоминания | запрашивать в контексте, не при старте |
| `com.android.vending.BILLING` | `in_app_purchase` | только для `BILLING_MODE=play` | в сборке `external` проверить, что покупки в UI недоступны |
| `com.google.android.gms.permission.AD_ID` | Firebase Analytics / Play services | **нет** (рекламы нет, аудитория 16+) | удалить через `tools:node="remove"` и отключить сбор рекламного ID в Analytics; тогда в Play Console — «не использует рекламный ID» |
| `WAKE_LOCK`, `RECEIVE` (C2DM) | `firebase_messaging` | да для пушей | — |
| Камера, хранилище, фото | `image_picker`, `file_picker`, `permission_handler` (не используются) | нет | удалить зависимости (DEP-01) |

## 8. Целевая аудитория и контент

- [ ] **[владелец]** Целевая аудитория: **16–17 и 18+**. Не выбирать группы
      младше 13 лет — иначе применяется политика Families
      ([answer/9867159](https://support.google.com/googleplay/android-developer/answer/9867159?hl=en)).
      Если сознательно ориентироваться на 10-классников 15 лет — добавить
      13–15 (Families всё равно не применяется), но учесть, что в некоторых
      странах 13–17 считаются детьми.
- [ ] **[владелец]** Анкета возрастного рейтинга IARC: насилия, азартных игр,
      покупок цифровых случайных наград нет; учесть, что есть публичные
      отображаемые имена в рейтинге и AI-чат.
- [ ] **[код, проверить]** Политика Google Play о контенте, созданном AI:
      в AI-репетиторе нужна возможность пожаловаться на ответ внутри
      приложения. Проверить, что пакет репетитора её добавил; если нет —
      доработка до релиза.
- [ ] **[владелец]** Декларации: реклама — нет; новости — нет; финансовые
      функции — нет; государственное приложение — **нет** (не намекать на связь
      с ЦООМО — политика о выдаче себя за другого).
- [ ] **[владелец]** Доступ для проверки («App access»): вход обязателен —
      дать проверяющим тестовый аккаунт (создаёт владелец, данные вводит сам в
      Play Console).

## 11. Матрица реальных устройств

| Класс | ОЗУ | Android | Экран | Что проверить |
|---|---|---|---|---|
| Флагман | 8 ГБ | 15–16 | 6,5″ | эталон, предиктивный «назад», тёмная тема |
| Средний | 4 ГБ | 12–13 | 6,1″ | основной сценарий, полный пробник 215 минут |
| Бюджетный | 3 ГБ | 10–11 | 6,0″ HD | холодный старт, плавность палитры вопросов, память на длинных текстах чтения |
| Очень бюджетный | 2 ГБ | 8–9 (Go-класс) | 5,0″, 360×640 dp | нет переполнений, система убивает приложение в фоне → восстановление попытки |
| Маленький экран + крупный шрифт | любой | любой | 360×640 dp, масштаб шрифта 1,3 | все экраны без обрезки текста |

Сценарии на каждом классе:

- [ ] Регистрация, вход email и Google (release-сборка с ключом Play App Signing).
- [ ] Бесплатный полный пробник: старт, переходы внутри раздела, отметки,
      закрытие раздела с подтверждением, истечение таймера → автозакрытие.
- [ ] Убить приложение посреди раздела (в «Параметрах разработчика» — «Не
      сохранять действия») → запуск → баннер восстановления, ответы на месте.
- [ ] Обрыв сети на границе раздела → экран «Нет соединения — повторить»,
      следующий раздел не стартует до подтверждения сервера.
- [ ] Медленная сеть (2G/3G, троттлинг) — время старта, отсутствие вечных
      спиннеров.
- [ ] Переключение языка ky ↔ ru, тёмная тема, поворот экрана (если не
      заблокирован).
- [ ] Повторный пробник без кредита → понятное состояние «нет доступа»
      (`NO_ENTITLEMENT`); в сборке `external` — без цен и ссылок.
- [ ] AI-репетитор: ответ, дневной лимит, запрет во время активной попытки.
- [ ] Удаление аккаунта → повторный вход невозможен, данные удалены.
