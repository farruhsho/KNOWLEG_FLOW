# Google Play Data safety — ответы для формы

> Черновик ответов на форму «Безопасность данных» в Play Console для ORT Master
> KG (версия 2026-11-02). Ответы должны совпадать с фактическим поведением
> приложения **и всех SDK** — перед отправкой сверить с итоговым манифестом,
> кодом пакетов модернизации и официальной таблицей Firebase
> ([firebase.google.com/docs/android/play-data-disclosure](https://firebase.google.com/docs/android/play-data-disclosure)).
> Требования Google: [answer/10787469](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en).

## 1. Общие вопросы формы

| Вопрос | Ответ | Пояснение |
|---|---|---|
| Собирает ли приложение или передаёт какие-либо из обязательных типов данных? | **Да** | |
| Все ли собираемые данные шифруются при передаче? | **Да** | Firebase и Cloud Functions работают только по HTTPS/TLS |
| Можно ли запросить удаление данных? | **Да** | в приложении (Профиль → Настройки → Удалить аккаунт) и на веб-странице `[https://домен/delete-account]` |
| Независимая проверка безопасности | Нет | — |
| Политика Families | Не применяется | целевая аудитория 16–17 и 18+ |
| Используется ли рекламный ID | **Нет** — при условии, что разрешение `AD_ID` удалено из итогового манифеста и сбор рекламного ID в Analytics отключён (см. [`PLAY_RELEASE_CHECKLIST.md` §6](PLAY_RELEASE_CHECKLIST.md#6-разрешения)) | иначе отвечать «Да, для аналитики» |

**«Передача» (sharing).** По определению Google передачей не считается
отправка данных поставщику услуг, который обрабатывает их от имени
разработчика. Google Firebase и Google Play — поставщики услуг; Anthropic
(AI-репетитор, вызывается только с нашего сервера) — поставщик услуг. Поэтому
во всех строках «Передаются третьим лицам» — **Нет**. Если появится
партнёрский обмен (например, отчёт для школы с данными ученика), ответ
пересматривается.

## 2. Типы данных

Обозначения: **Обяз.** — пользователь не может отказаться при использовании
функции; **Необяз.** — можно не указывать; **Врем.** — обрабатывается
временно, не сохраняется.

| Категория → тип | Собирается | Передаётся | Обяз./Необяз. | Цели | Откуда | Комментарий |
|---|:-:|:-:|---|---|---|---|
| Личная информация → **Имя** | Да | Нет | Обяз. | Функции приложения, управление аккаунтом | форма регистрации, Google Sign-In | отображаемое имя в рейтинге выбирает пользователь |
| Личная информация → **Email** | Да | Нет | Обяз. | Управление аккаунтом, функции приложения | Firebase Auth, Google Sign-In | рассылки — только с отдельного согласия; если их не будет, цель «связь разработчика» не указывать |
| Личная информация → **Идентификаторы пользователя** | Да | Нет | Обяз. | Функции приложения, управление аккаунтом, аналитика, защита от мошенничества и безопасность | Firebase Auth UID | |
| Личная информация → **Другая информация** | Да | Нет | Необяз. | Функции приложения, персонализация | профиль | класс, школа, область/район/населённый пункт, целевые вузы, язык экзамена, URL фото профиля Google |
| Личная информация → Телефон | Нет | — | — | — | — | поле `phone` есть в модели, но в текущей версии не заполняется; при появлении входа по телефону — объявить |
| Финансовая информация → **История покупок** | Да | Нет | Обяз. для покупателей | Функции приложения, защита от мошенничества, безопасность и соответствие требованиям | `purchases`, `entitlements/{uid}/ledger` | товар, время, статус, кредиты; в режиме `external` — записи о пополнениях с сайта |
| Финансовая информация → Платёжные данные | Нет | — | — | — | — | карту обрабатывает Google Play (или платёжный сервис на сайте); приложение данных карты не получает |
| Местоположение (точное / приблизительное) | Нет | — | — | — | — | разрешений на геолокацию нет; регион указывает сам пользователь (строка «Другая информация»). Сверить с таблицей Firebase для Analytics |
| Сообщения → **Другие сообщения в приложении** | Да | Нет | Необяз. | Функции приложения | AI-репетитор | текст вопроса пользователя и контекст задания отправляются на сервер и в Anthropic для ответа. Если текст не сохраняется на сервере (сохраняются только счётчики в `ai_usage`) — отметить «Врем.»; подтвердить по реализации `aiTutor` |
| Действия в приложении → **Взаимодействие с приложением** | Да | Нет | Обяз. | Функции приложения, аналитика | Firestore, Firebase Analytics | попытки экзаменов, завершённые уроки, XP, серии, события Analytics |
| Действия в приложении → **Другой пользовательский контент** | Да | Нет | Обяз. | Функции приложения, персонализация | Firestore | ответы на задания, отметки «вернуться», очередь ошибок |
| Действия в приложении → История поиска в приложении | Нет | — | — | — | — | поиск по предметам выполняется локально |
| Информация о приложении и производительность → **Журналы сбоев** | Да | Нет | Обяз. | Аналитика, функции приложения | Firebase Crashlytics | |
| Информация о приложении и производительность → **Диагностика** | Да | Нет | Обяз. | Аналитика, функции приложения | Crashlytics, Analytics | модель устройства, версия ОС и приложения, время старта |
| Устройство или другие идентификаторы | Да | Нет | Обяз. | Функции приложения, аналитика, защита от мошенничества и безопасность | Firebase Installations, FCM-токен, App Check / Play Integrity | рекламный ID — не собирается (см. раздел 1) |
| Фото и видео | Нет | — | — | — | — | загрузка файлов пользователями не предусмотрена |
| Аудио, файлы, календарь, контакты, здоровье, история браузера, установленные приложения | Нет | — | — | — | — | |

## 3. Какие SDK что собирают

| SDK / сервис | Данные | Где хранятся |
|---|---|---|
| Firebase Authentication | email, UID, имя и фото профиля Google, время входа | Google (проект `knowleg-33f36`) |
| Cloud Firestore | профиль, прогресс, попытки и ответы, кредиты и журнал покупок, очередь ошибок, рейтинги, счётчики AI | регион базы проекта (проверить в консоли) |
| Cloud Functions | запросы приложения (экзамен, покупки, AI, удаление) | регион функций (`europe-west1` по контракту) |
| Firebase Crashlytics | журналы сбоев, сведения об устройстве, installation ID | Google |
| Google Analytics for Firebase | события использования, installation ID, сведения об устройстве | Google; срок хранения в настройках Analytics — выбрать минимальный (2 месяца) |
| Firebase Cloud Messaging | FCM-токен | Google |
| Firebase App Check / Play Integrity | сигналы целостности устройства и приложения | Google |
| Firebase Remote Config | installation ID | Google |
| Google Play Billing (`in_app_purchase`) | токен покупки, товар, статус (только в режиме `play`) | Google Play + наш `purchases` |
| Anthropic API (через `aiTutor`) | текст вопроса и контекст задания; без имени, email и UID в запросе (рекомендация) | Anthropic, по коммерческим условиям Anthropic |

## 4. Что удаляется по запросу

| Данные | Удаление | Хранение после удаления |
|---|---|---|
| Аккаунт Firebase Auth | да | — |
| Профиль, прогресс, попытки, ответы, очередь ошибок, XP, достижения, записи в рейтингах | да | — |
| Записи о покупках и журнал кредитов | обезличиваются или удаляются | минимальный набор для бухгалтерии и защиты от мошенничества — срок определяет юрист (раздел «Хранение» в политике) |
| Журналы сбоев и аналитика | не привязаны к аккаунту напрямую | удаляются по срокам хранения Crashlytics/Analytics |

## 5. Перед отправкой формы

- [ ] Проверить итоговый манифест release-сборки: нет `AD_ID`, нет лишних
      разрешений.
- [ ] Сверить каждую строку с официальной таблицей Firebase для используемых
      SDK.
- [ ] Подтвердить, хранится ли текст сообщений AI-репетитора на сервере.
- [ ] Ссылки на политику конфиденциальности и страницу удаления работают без
      входа.
- [ ] Обновлять форму при каждом новом SDK или новом типе данных.
